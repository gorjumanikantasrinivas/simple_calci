Calculator 🧮

A clean, responsive Calculator built with vanilla HTML, CSS & JavaScript. Performs all basic arithmetic operations with a smooth, modern UI — no libraries needed.

Features

➕ Addition, Subtraction, Multiplication, Division
🔢 Decimal number support
⌫ Backspace to delete last digit
🔄 Clear (AC) button to reset
📱 Responsive — works on mobile and desktop


Tech Stack
LayerTechnologyStructureHTML5StylingCSS3LogicVanilla JavaScript

Getting Started

Clone the repository

bashgit clone https://github.com/gorjumanikantasrinivas/calculator.git

Open the project folder

cd calculator
Open index.html in your browser — no installs needed!


Project Structure
```
calculator/
├── index.html   → Layout and button structure
├── style.css    → Styling and responsive design
└── script.js    → Calculation logic
```
How to Use

Click number buttons to input digits
Choose an operator ( + − × ÷ )
Press = to see the result
Press AC to clear and start over
